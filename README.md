# 在线答题系统（多套试卷版）

一个零依赖的答题网站：**可以出很多套题，每套一个独立的答题链接和二维码**，出完点「发布」就能把链接发给别人答题。

后端使用 Node.js 内置模块 + JSON 文件存储，**不需要 `npm install`，不需要数据库**。

---

## 一、启动

双击 **`启动答题系统.cmd`**，或在命令行执行：

```bat
cd quiz-site
node server.js
```

启动后控制台会打印地址：

| 页面 | 地址 |
| --- | --- |
| 答题首页（试卷列表） | http://127.0.0.1:3210/ |
| 管理后台 | http://127.0.0.1:3210/admin |
| 某套试卷的答题链接 | `http://127.0.0.1:3210/p/XXXXXXXX`（由后台自动生成） |

**默认管理密码：`admin123`**（登录后请到「系统设置」修改）

> 换端口：`set PORT=8080 && node server.js`
> 给局域网内其他人答题：`set HOST=0.0.0.0 && node server.js`，然后把链接里的 `127.0.0.1` 换成你的内网 IP。

### 部署到服务器（让别人通过公网访问）

详见 **[DEPLOY.md](DEPLOY.md)** —— 腾讯云/阿里云轻量服务器从零到上线的完整步骤，含一键脚本：

```bash
cd /opt/quiz-site
sudo bash deploy/install.sh
```

也支持 Docker：`docker compose up -d --build`

## 二、出题的完整流程

1. 打开 `/admin`，登录。
2. 点 **「＋ 新建一套试卷」**，填个名字（例如「2026 春季语文测验」）。
   → 系统立刻为这套试卷生成一条**独立链接**和一个**二维码**，之后各套题互不干扰。
3. 进入这套试卷的工作区（左侧有工具菜单）：
   - **出新题** —— 一题一题手工加
   - **题库管理** —— 查看/编辑/删除/拖动排序，可按分值、正确率排序
   - **批量导入** —— 从 Word 粘贴或一行一题
   - **成绩记录** —— 只看这套试卷的提交，表头可排序
   - **数据统计** —— 按题、按人、按分数区间的统计分析
   - **试卷设置** —— 改名、说明、答题口令、本套及格线
   - **分享试卷** —— 大二维码 + 链接
4. 出完题，点右上角 **「发布」**。
5. 把**链接或二维码**发给要答题的人。

> 未发布的试卷是「草稿」，链接打不开；已发布的转回草稿后，链接也会立即失效。

### 右上角有什么

进入某套试卷后，页面**右上角**始终显示：

```
← 试卷列表 | 试卷名称 |  🔗 http://127.0.0.1:3210/p/XXXXXXXX  |  ▦ 二维码  |  已发布/草稿  |  发布/取消发布
```

- 点 **🔗 那条链接** = 一键复制
- 点 **▦ 二维码** = 弹出二维码，可**复制链接**或**下载 PNG**（打印出来贴墙上扫码答题）

试卷列表里每张卡片也有同样的链接、二维码、复制、重命名、复制副本、发布、删除按钮。

## 三、出题的三种方式

### 1. 手工一道一道出（最快）

- 切换「单选题 / 简答题」
- 填题干 → 填选项（点左侧圆圈标记正确答案）
- 选项框按 **回车** 自动新增下一个选项，空选项框按 **退格** 删除
- **Ctrl + Enter** 保存
- 点 **「保存并继续出题」**：存完自动清空表单并聚焦题干，可以连续快速出题
- 表单下方有一条**实时总分带**，边出题边看：

  ```
  本套试卷共 6 题  |  当前总分 9 分            加上本题 → 7 题 / 10 分
  ```

  改「本题分值」会实时重算；编辑已有题目时显示「保存后 → N 题 / M 分」。

### 改试卷名字

三个地方都能改，改完立即生效（链接和二维码不变）：

- 试卷列表里每张卡片的 **「重命名」**
- 进入试卷后，**右上角试卷名旁边的 ✎**，点一下就能改
- 「试卷设置」里的 **试卷名称** 输入框

> 试卷码（链接里的 `XXXXXXXX`）与试卷名无关，改名不会让已发出去的链接失效。

### 2. 批量导入（从 Word / 文档直接粘贴）

```
1. 中国的首都是哪座城市？（2分）
A. 北京
B. 上海
C. 广州
答案：A

2. 请写出三种颜色
答案：红色、绿色、蓝色
```

或者一行一题：

```
单选|中国的首都是哪座城市？|北京|上海|广州|A
简答|请写出三种颜色|红色、绿色、蓝色
```

规则：
- 题号 `1.` `1、` `(1)`，选项标号 `A.` `A、` `A)` 都能识别
- 题干末尾的 `（2分）` 会作为分值，默认 1 分
- **有选项 = 单选题，没有选项 = 简答题**
- 简答题答案用 `、` 分隔多个值
- 可以 **「解析预览」** 先看解析结果，再 **追加** 或 **清空并替换** 本套试卷

### 3. 复制已有试卷

在试卷列表点 **「复制副本」**，题目全部带过去，链接是新的，状态为草稿 —— 适合"改一改再出一套"。

## 三点五、统计与排序

后台不只是编辑题目，还能看数据和排序。

### 成绩记录（先筛选，再出结果）

进入「成绩记录」**不会直接列出所有记录**，而是先给你一张筛选面板：

| 筛选项 | 说明 |
| --- | --- |
| **姓名** | 按姓名包含匹配 |
| **试题** | 下拉选某一道题 |
| **该题结果** | 配合「试题」用：答对 / 部分正确 / 答错 / 未作答 |
| **得分率** | 最低 ~ 最高（%） |
| **是否及格** | 不限 / 仅及格 / 仅不及格 |
| **提交日期** | 起始 ~ 结束日期 |

选好后点 **「查询」** 才显示结果；点 **「重置」** 清空条件。什么都不选直接查询 = 查看本套全部记录。

查询结果里：

- 顶部统计卡片：命中记录数、涉及人数、平均得分率、及格份数、最高、最低
- 标题显示**命中条数**，右侧显示**当前筛选条件**，避免看错数据
- 选了「试题」时，表格会**多出一列「第 N 题结果」**，显示该题得分和「正确 / 部分正确 / 错误 / 未作答」徽章
- **点表头排序**：名次 / 姓名 / 提交时间 / 用时 / 总分 / 得分率 / 该题得分 / 答对题数，点一次升序、再点降序，表头用 ▲▼ 提示
- 每行可「查看答卷」或删除；右上角可**导出明细 CSV**（导出的是当前筛选结果所在试卷的全部明细）

> 例：想找「第 3 题答错的所有人」→ 试题选第 3 题、该题结果选「答错」→ 查询。

### 数据统计（新的独立页面）

**概览卡片**：提交份数、参与人数、平均得分率、中位数、最高、最低、及格率、平均用时。

**分数分布**：0-10% … 90-100% 共 10 档的横向条形图，一眼看出成绩集中在哪一段。

**按人员统计**（同名多次提交自动合并）：

| 列 | 说明 |
| --- | --- |
| 姓名 / 提交次数 | 谁交了几次 |
| 最高得分率 / 最近得分率 / 平均得分率 | 三种口径的分数 |
| 是否及格 | 按本套试卷的及格线 |
| 最近提交 | 时间，可点「看最近一次答卷」 |

点表头可排序，支持按姓名搜索，可**导出人员成绩 CSV**。

**按题目统计** —— 找出哪道题最难：

- 每题显示：**正确率**（≥80% 绿 / ≥50% 橙 / <50% 红）、答对 / 部分对 / 答错 / 未作答人数、平均得分
- **单选题显示每个选项被选的人数与占比条形图**，正确答案标绿并打「正确答案」标签；能直接看出干扰项是不是有效
- **简答题显示标准答案 + 学员最常见的错误答案**（出现次数）
- 顶部可切换排序：按题号 / 正确率低→高（最难在前）/ 正确率高→低 / 平均得分
- 可**导出题目统计 CSV**

### 题库管理里的排序

上方多了个排序下拉，只影响**列表展示**，不改变答题顺序：

- 手动顺序（答题顺序，默认）
- 分值 高→低 / 低→高
- 正确率 低→高（最难在前）/ 高→低
- 按题干

选了非手动顺序时，列表里的每道题会直接显示它的正确率；此时拖拽手柄和上下移动按钮会隐藏（避免和答题顺序混淆），切回「手动顺序」即可继续拖拽调整。

> 只要有成绩，题库列表顶部还会显示这套卷的**平均正确率**。

## 四、答题端

- **答题首页 `/`**：列出所有已发布的试卷，点进去答题。
- **专属链接 `/p/XXXXXXXX`**：直接进入某套试卷，页面顶部显示试卷名，右上角有「其他试卷」返回。

答题页功能：

1. **填写姓名** —— 必填（本地记住上次姓名）
2. **单选题** —— 点击选项高亮
3. **简答题** —— 单个输入框，**多个值用顿号 `、` 分隔**，实时提示「N 个值」
4. **提交按钮** —— 有未作答的题会先弹窗提醒

提交后跳转 **成绩页**：圆环百分比 + 及格徽章 + 四项统计 + **全部题目/你的答案/正确答案**，**错题红色高亮**、部分正确橙色，答对要点打 ✔ 答错打 ✘。支持「全部 / 只看错题 / 只看正确」筛选和打印存 PDF。

### 答题口令（可选）

在「试卷设置」里给某套试卷设一个口令，别人打开链接后必须输入口令才能看到题目。
适合"只想让某几个人答"的场景。口令会显示在后台的「分享试卷」页，方便你一起发给答题人。

### 判分规则

| 题型 | 规则 |
| --- | --- |
| 单选题 | 选对得满分，选错或未答得 0 分 |
| 简答题 | 全部答对得满分；漏答/多答按 `答对个数 ÷ max(标准答案数, 你的答案数)` 给部分分（可按试卷关闭）；未作答得 0 分 |

每题分值单独设置；**及格线和"部分给分"可以全站默认，也可以按试卷单独覆盖**。

    ├── test-api.js          接口端到端自测（79 项）

## 六、API 一览

### 答题端

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/config` | 网站标题等公开配置 |
| GET | `/api/papers` | 已发布试卷列表 |
| GET | `/api/papers/:code` | 某套试卷的信息（是否有口令、题数、总分） |
| POST | `/api/papers/:code/questions` | 取题目（带 `accessCode`；**不含正确答案**） |
| POST | `/api/papers/:code/submit` | 提交答卷 |
| GET | `/api/result/:id` | 答卷详情（成绩页用） |

### 管理端（需请求头 `x-admin-token`）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/admin/login` | 登录 |
| GET/POST | `/api/admin/papers` | 试卷列表 / 新建试卷 |
| GET/PUT/DELETE | `/api/admin/papers/:id` | 读取 / 修改 / 删除某套试卷 |
| POST | `/api/admin/papers/:id/publish` | 发布 / 转为草稿 |
| POST | `/api/admin/papers/:id/duplicate` | 复制为新试卷 |
| GET/POST | `/api/admin/papers/:id/questions` | 本套题目列表 / 新增 |
| PUT/DELETE | `/api/admin/papers/:id/questions/:qid` | 修改 / 删除某题 |
| POST | `/api/admin/papers/:id/questions/reorder` | 保存题目顺序 |
| POST | `/api/admin/papers/:id/preview` | 只解析不导入（导入预览） |
| POST | `/api/admin/papers/:id/import` | 批量导入到本套 |
| GET | `/api/admin/papers/:id/stats` | **统计：概览 / 分数分布 / 按题 / 按人** |
| GET | `/api/admin/submissions` | 成绩列表。可选参数：`paperId` `name` `qid` `qstatus` `minPercent` `maxPercent` `pass` `from` `to` |
| GET | `/api/admin/export?format=json\|csv&paperId=&type=` | 导出题库 / 成绩明细 / `type=questions` 题目统计 / `type=students` 人员成绩 |
| POST | `/api/admin/settings` | 全站设置 / 改密码 |

密码使用 sha256 + 随机盐存储；**正确答案不下发到答题端**，前端改不了分。

## 八、说明与限制

- 数据存在单个 JSON 文件里，适合班级/机构/内部使用；并发量很大时建议换数据库。
- 服务默认只监听 `127.0.0.1`（只有本机能访问）。要给局域网其他人用请设 `HOST=0.0.0.0`，此时没有 HTTPS。
- 链接里的试卷码是 8 位随机码（去掉了容易混淆的 `I/L/O/0/1`），猜不到；但**拿到链接的人都能答题**，需要限制就用「答题口令」。
- 简答题按「要点集合」比对，不做语义理解，同义不同词会判错。
- 「删除试卷」会**同时删除它的成绩记录**，操作前会让你输入 `DELETE` 确认。
